# gmaendel/tap

Homebrew casks for gmaendel's Mac apps.

```bash
brew install --cask gmaendel/tap/multiplesoundoutput
```

| Cask | App |
| --- | --- |
| `multiplesoundoutput` | [MultipleSoundOutput](https://github.com/gmaendel/MultipleSoundOutput): plays sound through several displays at once, with working volume keys |
